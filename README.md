# 🛠️ Serviços Locais — Plataforma de Conexão para Profissionais Autônomos

O **Serviços Locais** é uma Landing Page de alta conversão projetada para conectar clientes a profissionais autônomos e prestadores de serviços locais (como eletricistas, encanadores, pintores, entre outros). O foco principal do projeto é oferecer uma experiência fluida de navegação, unindo um design moderno a estratégias sólidas de marketing digital, captação de leads e análises de métricas.

> 📢 **Nota de Portfólio:** Este projeto foi desenvolvido exclusivamente para fins de demonstração técnica e apresentação de portfólio freelance. Os dados de contato, endereços e links para redes sociais são fictícios e altamente funcionais, criados para simular um ambiente de produção real.

---

## 🚀 Funcionalidades Principais

*   **Filtro Visual de Categorias:** Tags interativas mapeando mais de 14 especialidades (Eletricista, Encanador, Pedreiro, Marido de Aluguel, Diarista, etc.) para facilitar a identificação visual do cliente.
*   **Fluxo de Contratação Guiado:** Seção descritiva "Como Funciona" estruturada em etapas simples (Solicitação de Orçamento $\rightarrow$ Atendimento $\rightarrow$ Problema Resolvido) para quebrar objeções do usuário.
*   **Prova Social Estruturada:** Seção dedicada a avaliações e depoimentos de clientes integrando uma simulação realista de notas do Google Business.
*   **Central de Ajuda (FAQ interativo):** Sistema de *Accordion* desenvolvido em JavaScript puro para sanar as dúvidas mais frequentes sem poluir o visual da página.
*   **Formulário Avançado de Captação:** Formulário completo segmentado por tipo de serviço (Residencial, Comercial, Outros) com validação de campos e localização.
*   **Aviso de Privacidade (LGPD):** Banner de consentimento de Cookies totalmente funcional, respeitando as conformidades da legislação vigente.

---

## 📈 Integrações, Marketing & Analytics

Este projeto foi construído pensando além do código, estruturado com ferramentas essenciais para o crescimento de qualquer negócio digital:

*   **Formspree Integration:** O formulário de contato é 100% integrado ao Formspree, garantindo o recebimento e armazenamento dos leads em tempo real de forma segura.
*   **Google Tag Manager (GTM):** Centralização e gerenciamento de todos os scripts de rastreamento de forma otimizada, evitando perda de performance no carregamento da página.
*   **Google Analytics 4 (GA4):** Integrado via GTM para monitorar o comportamento do usuário, cliques em botões de conversão (CTA), taxa de rejeição e preenchimento de formulários.
*   **Parâmetros de URL & UTMs:** Código preparado para rastrear a origem do tráfego (Google Ads, Facebook Ads, Tráfego Orgânico), ideal para auditorias de campanhas de marketing.
*   **SEO Otimizado:** Arquitetura de cabeçalhos ($H1$, $H2$, $H3$), uso correto de tags semânticas e configurações de Meta Tags/Open Graph para garantir excelente indexação em motores de busca.

---

## 🛠️ Tecnologias Utilizadas

A stack do projeto foca em alta performance, carregamento instantâneo e estilização responsiva:

*   **HTML5:** Estruturação semântica avançada.
*   **Tailwind CSS:** Framework utilitário para um design responsivo, moderno e de carregamento ultra-rápido.
*   **JavaScript (Vanilla JS):** Lógica nativa para manipulação do DOM (FAQ, Banner de Cookies, interações) sem dependências pesadas de terceiros.
